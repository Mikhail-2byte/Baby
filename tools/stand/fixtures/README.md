# Записи для акта 4

Надиктовать с телефона и положить сюда. Что говорить — в `tools/stand/act4.py`,
словарь `SCRIPT`: имя файла там ключ, а рядом написана фраза.

Синтезировать эти файлы нечем: TTS в зависимостях проекта нет, и появляться ему
незачем. Подсунуть вместо голоса тишину тоже нельзя — тогда акт проверял бы
расшифровку на пустом файле, то есть ничего.

Формат — любой, который принимает Telegram как голосовое: телефон отдаёт
`ogg/opus`, и он же уходит в Whisper как есть, без конвертации.

Записи в `.gitignore` не попадают намеренно: шаг, вход которого надо
надиктовывать заново на каждой машине, не будет запущен ни разу.
